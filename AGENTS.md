# Project Context

- **Package Manager:** `uv`
  - Add dependencies: `uv add <package>` && `uv sync`
  - Run project: `uv run <command>` (e.g., `uv run main.py`)
- **Functionality:**
  - Uses LLMs via API.
  - Reads text data (transcriptions) from `.data` directory.
  - Processes the transcribed text.
